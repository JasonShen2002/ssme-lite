02
PERFORMANCE & RANKING

模型表现与排名

PERFORMANCE

模型表现，逐项比较。

从整体分类、区分能力、正类检索和概率校准四个角度比较候选模型。ECE 越低越好，其余指标越高越好。

Accuracy ↑

预测类别正确的比例。点估计直接计算后验下的正确率期望；类别不平衡时，需要结合 AUPRC 等指标理解。

AUC ↑

ROC 曲线下面积，衡量模型把正类排在负类前面的能力。二分类使用正类概率，多分类使用 macro OvR。

AUPRC ↑

这里以 Average Precision（AP）实现，概括 precision–recall 表现。多分类使用 macro OvR；数值与类别比例有关。

ECE ↓

概率校准误差，按 10 个等宽区间计算并以样本数加权。二分类校准正类概率，多分类校准 top-label confidence。

Performance matrix

按每列指标的相对表现着色

四张图均按 M01 → M02 → … 的输入顺序排列，与上表逐行对应；紫色表示当前指标的领先点估计。横轴按各指标分别缩放，不能跨图比较点之间的几何距离。

点表示性能估计，细线表示 中央抽样区间。Accuracy 使用精确后验期望，AUC、AUPRC 和 ECE 使用有效抽样的均值。区间来自同一拟合后验下的潜在标签抽样，越窄仅表示这一来源的变化越小。

SAMPLING & RANKING

一次抽样，同时观察数值与名次。

同一批潜在标签抽样，连接指标分布、模型排名和两两差距；这三个视角共同描述抽样变化。

例如某个样本的后验为 P(class 1) = 0.7，它在每次抽样中有 70% 的机会被赋为 class 1。重复抽样后，Rank distribution 统计每个模型处于各名次的频率；Pairwise sampling frequency 统计行模型优于列模型的频率。这里重复的是标签抽样，并没有重新训练模型或重新拟合 SSME。

Rank-1 stability 是 sampled evaluations 中的频率，不是真实最优模型的概率。Top-2 使用同一并列分配规则。

同一批抽样，指标数值变化多大？

Metric sampling view

分布图把一个模型在每次抽样中的指标值汇集起来；下方配对比较使用同一次抽样计算 A 与 B 的差值。例如 Accuracy 的 Δ = 0.002，表示该次抽样中 A 比 B 高 0.2 个百分点。若所有抽样的指标几乎相同，分布就会收缩成一个点。

Sampled metric distributions

轮廓为抽样密度，粗线为四分位区间，点为中位数。没有可见变化时仅显示单点，不人为扩展分布。
